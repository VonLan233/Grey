# Grey P6–P10 与 v1.0 发布实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` to implement this plan task-by-task. Every task follows red → green → spec review → quality review → atomic commit.

**Goal:** 安全收尾 P6，逐项完成 P7–P10，内建 ChatGPT Plus/Pro 浏览器 OAuth，保留 OpenAI API Key 与 OpenCode Go/Zen，并提供可由用户一键执行的完整离线、live 和长稳测试。

**Architecture:** 不新增 workspace crate。`grey-core` 承担原始配置编辑、运行时限制与受限子进程；`grey-provider` 承担分类错误、Responses 与 ChatGPT OAuth；`grey-tools` 复用受限进程并新增最小 MCP stdio；`grey-tui` 使用同一运行时限制和 Gray Tempest token。所有扩展在既有 trait/registry 上收口。

**Tech Stack:** Rust 1.97.1、Tokio、Reqwest/rustls、Serde、Ratatui、`toml_edit`、`keyring`、`rand`、`base64`、`url`、外部 Wasmtime、cargo-dist 0.32.0。

**Spec:** `docs/superpowers/specs/2026-08-19-p6-p10-release-design.md`
